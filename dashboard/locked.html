Access is gated

The console is not reachable by URL alone. Authenticate through the AgentSOC SSH gateway to receive a one-time access link.

$ ssh soc@<server-ip> -p 2222 # password: your gateway password # then open the one-time URL it prints

After the SSH gate you will enter the admin email and a one-time code (OTP) before the console opens.
